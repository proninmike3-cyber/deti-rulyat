# Дети Рулят! — демонстрационный сайт

Одностраничный адаптивный сайт для точки проката детских электромобилей в ТРЦ «Акварель», Пушкино.

## Запуск

Откройте `index.html` в браузере или опубликуйте папку как статический сайт (например, GitHub Pages, включив публикацию из корневой папки ветки `main`). Сборка, сервер и административная панель не нужны.

## Что реализовано

- Мобильная и десктопная адаптивная верстка, закрепленная шапка и мобильное меню.
- Контакты (звонок, Telegram, ВКонтакте), переход к карточке Яндекс Карт.
- Прайс на 10 минут: будни 400 ₽ / 450 ₽ (1 / 2 ребёнка в машинке), выходные 500 ₽ / 550 ₽.
- FAQ по цене, возрасту, записи, расположению и графику.
- SEO-метаданные и JSON-LD разметка.
- Все визуальные элементы — локальные SVG; внешние серверы для изображений не используются.
- Никакие формы не собирают персональные данные.
